# Magavis

**Переводчик экрана для Android: манга, манхва и маньхуа — перевод прямо в облачках.**
Screen translator for Android: manga, manhwa and manhua translated right inside the speech bubbles.

🌐 [magavis.com](https://magavis.com) · ✉️ support@magavis.com

## Что умеет

- Находит облачки на странице и ставит перевод прямо в них, не ломая вёрстку страницы.
- Облачный перевод комиксов: живая речь с учётом всей страницы — кто говорит, с кем и о чём.
- Перевод на телефоне без интернета: машинный перевод и ИИ-модель на устройстве.
- 59 языков интерфейса и перевода.
- Игры, видео и любая область экрана — в разработке.

## Установка

1. Скачайте `Magavis-…-arm64.apk` в разделе [Releases](https://github.com/Ducitsemjon/magavis/releases) (для старых телефонов — `armv7`).
2. Откройте файл и разрешите установку из этого источника.
3. При первом запуске: подписка или ключ → проверка облака → разрешение «Поверх других приложений» → «Начать».
